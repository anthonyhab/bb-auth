bb-auth prompt screens

One sheet for every privileged request, with a screen shaped for each kind of command. The top half is what bb-auth verified about the request. What the agent says about it sits below, in quotes. The raw command is one keypress away on every screen.

Palette
Field
Facts firstThe title and details come from pkexec and the system, never from the agent.
One signal per stateThe sheet glows because it is the current thing. Focus is a 1px accent ring. Warnings are a short tick, not a banner.
Say what is unknownA preview that could not read a path, or was cut short, says so on the row.
Keyboard owns itEnter allows, Esc denies, Tab opens the exact command. The agent cannot type here.
